# Lab Questions - Programming Exercises

## Lab 1

1. WAP to find the area of the rectangle.

2. WAP to find simple interests.

3. Write a C program to find the area and volume of sphere and display the results.
   - Formulas:
     - Area = 4*PI*R*R
     - Volume = 4/3*PI*R*R*R
   - Note: Assume PI=3.14 and take the value of R from user

4. Write a program to evaluate the area of triangle with 3 sides given and display the result (take the value of sides from user as input).
   - Hints: area=sqrt(s(s-a)(s-b)(s-c)) where a,b,c are the sides of the triangle and s=(a+b+c)/2

5. Write a C program to find the sum of individual digits of a 3 digit number.

6. Write a program to swap two variable values with or without using a third variable.

7. Write a program to compute amount of electric bill as per charge below:
   - No of Units Consumed | Rates (in Rs.)
     - 500 and above      | 5.50
     - 200-500            | 3.50
     - 100-200            | 2.50
     - Less than 100      | 1.50

8. Write a C program which takes two integer operands and one operator from the user, performs the operation and then prints the result. (Consider the operators +,-,*, /, % and use Switch Statement)

9. Write a program to test if the character is digit or alphabet or special character on given conditions.
   - Character | Message
     - 0-9      | Alpha Digit
     - a-z      | Alpha lower case character
     - A-Z      | Alpha Uppercase character
     - Other    | special character

10. Write a program to find the middle number among 3 numbers.

11. WAP to ask two numbers and find out they are the same or greater than.

12. WAP to ask two integer number and perform mathematical operations by using operators (+,-,*,/,%) using a switch case.

13. WAP to ask age of a person and tell him/her age group as mentioned below:
    - Age Group | Category
      - 0-5      | Child
      - 6-12     | Young
      - 13-19    | Teen
      - 20-40    | Adult
      - Above 40 | Old

14. A company pays its employees on an hourly basis. If an employee works for 8 hrs he gets Rs.100/- hrs and 120/- hrs for additional hours. Write a program to read working hours of an employee and calculate the wages.
