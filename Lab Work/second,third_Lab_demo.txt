Lab 2 Report: Basic Numeric Operations in C Programming

Introduction
This lab explores fundamental C programming techniques for numeric processing, including comparisons, prime generation, matrix transposition, recursive sequences, and iterative series. These exercises reinforce control structures like loops and conditionals essential for algorithmic problem-solving.

Objectives
- To strengthen understanding of conditional statements and iterative loops.
- To practice array manipulation, sorting, and matrix operations.
- To implement structures and unions for organizing complex data.
- To apply pointers for direct memory access and manipulation.
- To develop problem-solving skills through mathematical and logical programming tasks.

Software and Tools Used
- Operating System: Windows 10/11, Linux (Ubuntu), or macOS.
- Integrated Development Environment (IDE): * Code::Blocks: A popular, open-source IDE used for C/C++ development.
- Dev-C++: A lightweight IDE often used in academic environments.
- Visual Studio Code (VS Code): A modern editor with C/C++ extensions and a terminal.
- Turbo C++: A classic (legacy) compiler still used in some curricula for learning fundamentals.
- Compiler: GCC (GNU Compiler Collection) or MinGW (Minimalist GNU for Windows).
- Documentation Tool: Microsoft Word or Google Docs for formatting the report, and Snipping Tool/Command+Shift+4 for capturing output results.

Results
The lab exercises demonstrated the following outcomes:
- Lab 2 (Control Structures and Arrays)
- Programs successfully identified the largest and middle numbers among three inputs.
- Factorization and prime number generation reinforced loop and conditional logic.
- Sorting roll numbers and matrix transpose tasks demonstrated array manipulation.
- Fibonacci and Hailstone series programs showcased iterative problem-solving.
- Lab 3 (Structures, Unions, and Pointers)
- Student and employee records were stored and displayed using structures.
- Nested structures allowed handling of complex data like date of birth.
- Unions were applied to manage employee records with shared memory.
- Pointer-based programs successfully displayed values and addresses, swapped variables, and checked even/odd numbers.
- Sorting and factorization using pointers highlighted memory-level operations.
Overall, each program achieved its intended purpose, reinforcing both theoretical and practical aspects of C programming.

Conclusion
This lab provided hands-on experience with intermediate C programming concepts. Students learned how to manipulate arrays, matrices, and series using loops and conditionals. Structures and unions introduced efficient ways to organize and manage data, while pointers offered direct control over memory. These exercises not only improved programming proficiency but also prepared students for advanced topics such as dynamic memory allocation, file handling, and data structures.
